# Safety Plan: NFG-PHYS-2026-01
Applies to all testers and handlers. **Safety overrides every objective.**

## 1. Pre-Engagement Safety Briefing Checklist
- [ ] Signed Scope, ROE, and Authorization Letter in hand (paper copy per tester)
- [ ] Landlord consent received for Site B (else Site B is cancelled)
- [ ] Each tester's ID verified and listed on the letter
- [ ] Review of targets, routes, time windows, and out-of-scope areas (tenant exclusions)
- [ ] Review abort triggers and incident protocols (ROE section 5-6)
- [ ] Pairs assigned; handler and backup handler confirmed
- [ ] Duress phrase rehearsed (not written next to its meaning)
- [ ] Medical form and emergency contacts collected
- [ ] Equipment check (section 2); phones charged and tested with handler
- [ ] Vehicle staging points reviewed; driver identified
- [ ] Client Security Lead confirmed reachable; test call completed
- [ ] Fit-to-test check: no alcohol/drugs, rested, no illness
- [ ] Everyone confirms right to stop at any time

## 2. Personal Safety Equipment (each tester)
- Phone **fully charged** + power bank; location sharing on with handler
- Flashlight (with spare batteries)
- Compact first-aid kit (plasters, bandage, gloves, antiseptic)
- Signed authorization letter + emergency card (paper, waterproof sleeve)
- Photo ID
- Water, comfortable non-slip footwear, business-like clothing that doesn't resemble a uniform
- Personal medication (as relevant)

## 3. Buddy System
- Minimum **two testers** present at the site during any testing.
- **No solo after-hours testing under any circumstances.** After-hours = outside 07:00-19:00 or on a weekend.
- Buddies stay within communication range and line of sight where practical; if separated, both stop and re-group.
- A third person (driver/handler) remains outside or reachable.

## 4. Check-in Schedule
- Mandatory check-in with the designated handler **every 2 hours** (text "CHECK-IN [time] OK/ID"), and at start and end of each shift.
- Handler logs all contacts. Example for day shift 07:00-19:00: 07:00, 09:00, 11:00, 13:00, 15:00, 17:00, 19:00 (end).
- Check-in is also required when entering a high-risk phase (data center attempt), and after any incident.

## 5. Communication Failure Protocol
| Time after missed check-in | Action |
|---|---|
| **+0 min** (check-in due) | Handler calls tester A, then B. |
| **+10 min** | Handler tries both again plus texts. Buddy in vehicle goes to staging point/perimeter. |
| **+15 min** | Handler calls the Tester Engagement Lead (to inform) and **Client Security Lead** to request a discreet welfare check and to ask whether any incident/detention is known. |
| **+25 min** | If still unreachable: **engagement is aborted.** All other testers stop and withdraw. Handler calls **Client Sponsor**. |
| **+30 min** | Handler calls **Police non-emergency line**; if there is any sign of danger, injury, or duress, call **112** immediately (no waiting). Provide names, location, descriptions, and show authorization letter details. |
| **+45 min** | Handler calls tester's emergency contact; escalate to Engagement Lead, firm's legal counsel. |
| Ongoing | Handler stays on until located; no further testing until Client Sponsor and Engagement Lead agree in writing. |

**Call order:** (1) Tester buddy → (2) Engagement Lead → (3) Client Security Lead → (4) Client Sponsor → (5) Police (non-emergency, or 112 if danger) → (6) Emergency contact. **Duress or injury skips straight to 112.**

## 6. Duress Code
- **Duress phrase (to be set at briefing, not reused):** *"I need to check the blue folder."*
- Used by phone/text: Tester inserts the phrase into a call/text to handler (e.g. "Can you send me the blue folder?").
- Handler response: continues the conversation normally, does not mention the code, asks innocuous questions to gauge status, then calls **112** and Client Security Lead immediately with the last known location.
- **Safe phrase**, to confirm everything is fine after a duress check: *"The green folder is in the car."*
- A tester who is in genuine physical danger does not need to use code: call 112.

## 10. Stand-Down Criteria
Tester may stop at any time. Stop if tired, ill, or uncomfortable; if the situation feels unsafe; if confronted by anyone aggressive; or if there are signs of a real incident. No penalty for stopping.
