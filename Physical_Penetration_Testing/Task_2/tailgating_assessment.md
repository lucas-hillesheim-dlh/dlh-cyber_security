# Tailgating Assessment — Sentinel Defense Systems (Fictional)
*Planning document for an authorized, scoped engagement. Each attempt requires sign-off under the ROE before execution; this table is the pre-approval plan, not an after-the-fact record.*

## Opportunity 1 — Morning tailgate at main entrance turnstiles
| Field | Detail |
|---|---|
| Time Window | 07:45-08:30 (peak arrival) |
| Entry Point | Main entrance turnstiles (reception/turnstile area) |
| Method | Tailgating (follow without the employee's knowledge) |
| Props | Laptop bag, visible (non-functional/visually generic) lanyard, coffee cup in free hand |
| Cover Story | None needed if undetected; if challenged: "Sorry — I thought my badge just read, let me try again" while stepping back out, then disengage |
| Risk Level | Medium |
| Success Estimate | 55% |
| Countermeasures | Turnstiles with strict anti-passback/one-badge-one-person enforcement; staff trained to notice a second person entering on one badge read |
| Counter-Detection Risk | Receptionist glancing up repeatedly at the turnstile area; a badge-read failure tone drawing attention |

## Opportunity 2 — Piggyback via loading dock during delivery window
| Field | Detail |
|---|---|
| Time Window | Scheduled delivery window (confirm via OSINT/pretext call ahead of time) |
| Entry Point | Loading dock personnel door |
| Method | Piggybacking (with apparent, if unverified, consent — e.g. dock staff waves the "delivery" through) |
| Props | Delivery uniform, clipboard, a wrapped package addressed to a real (publicly known) employee name |
| Cover Story | "Direct delivery, needs a signature from [name], fragile, can't leave at dock" |
| Risk Level | Medium-High |
| Success Estimate | 60% |
| Countermeasures | Dock staff trained to call ahead for all "direct to employee" deliveries rather than waving them through; dock door never left open/unattended |
| Counter-Detection Risk | Dock staff asking to just take the package themselves (a sign the pretext isn't working); a call placed to the named employee to confirm |

## Opportunity 3 — Group piggyback at lunch return
| Field | Detail |
|---|---|
| Time Window | 12:45-13:15 (lunch return, groups re-entering together) |
| Entry Point | Main entrance turnstiles |
| Method | Piggybacking within a group of 3+ returning employees |
| Props | Business-casual dress matching observed norm, phone held to ear (appearing mid-call to reduce conversational engagement) |
| Cover Story | If questioned: "Just getting back from lunch with the team" while gesturing to the group (do not name a specific person unless pre-cleared) |
| Risk Level | Low-Medium |
| Success Estimate | 50% |
| Countermeasures | One-badge-one-person turnstile enforcement; staff culture of not holding doors for unfamiliar faces even in a group |
| Counter-Detection Risk | A group member turning back to ask "do you work here?"; turnstile alarm on double-entry |

**Reporting note:** "Success estimate" figures are planning assumptions for prioritizing which attempts to schedule first, not guarantees — they should be revised after the first live attempt based on what's actually observed.
